# 📚 班级学生管理系统

初中班主任专用的班级管理 Web 应用，集成**学生信息管理、量化积分、成绩追踪、事件记录**等功能，配备 **AI 助手**支持自然语言查询与操作。

## 功能概览

| 模块 | 功能 |
|------|------|
| **首页仪表盘** | 班级概况卡片、积分 Top5/需关注学生、最近事件、最近考试、AI 助手对话 |
| **学生管理** | 学生增删改查、学号管理、批量操作、按小组筛选 |
| **积分管理** | 每周积分录入、自动累计、积分可视化图表 |
| **成绩管理** | 考试创建、科目成绩录入、班级均分/最高/最低分析 |
| **事件记录** | 违纪、表扬、谈话、家访等事件追踪 |
| **数据导入** | 支持 Excel 批量导入学生信息、学号、考试成绩 |
| **AI 助手** | 自然语言查询班级数据、执行修改操作（支持文件上传） |

## 技术栈

- **后端**: Python 3.12 + Flask
- **前端**: Alpine.js + Tailwind CSS + Chart.js
- **数据库**: SQLite
- **图标**: Lucide Icons
- **AI 接入**: OpenAI 兼容 API（支持 DeepSeek、OpenAI 等）

## 快速开始

### 1. 克隆仓库

```bash
git clone https://github.com/jrveseon/studentsmanager.git
cd studentsmanager
```

### 2. 安装依赖

```bash
pip install flask openpyxl
```

### 3. 启动应用

```bash
python app.py
```

访问 `http://localhost:5000`

### 4. 配置 AI（可选）

在设置页面填入 API Key 和模型信息：
- 支持 OpenAI、DeepSeek 等兼容 API
- 开启后可通过自然语言查询和操作数据

## 数据架构

系统支持**按届次隔离数据**，每个届次包含独立的学生、积分、成绩、事件数据：

```
届次 (cohorts)
 ├── 学期 (semesters)
 ├── 学生 (students)
 │    ├── 量化积分 (weekly_points)
 │    └── 事件记录 (events)
 └── 考试 (score_exams)
      └── 科目成绩 (score_items)
```

## 主要功能详解

### 📋 学生管理
- 添加/编辑/删除学生信息（姓名、学号、性别、民族、家庭信息等）
- Excel 批量导入导出
- 按小组筛选、关键词搜索

### ⭐ 量化积分
- 每周录入加分/减分
- 自动累计学期总分
- 积分排行榜（Top5 + 需关注学生）
- 生成可视化折线图

### 📝 成绩管理
- 创建考试（期中、期末、月考等）
- 录入各科目成绩
- 自动计算班级均分、最高分、最低分
- 考试历史记录

### 🔔 事件记录
- 违纪、表扬、谈话、家访等类型
- 时间线展示
- 与量化积分联动

### 🤖 AI 助手
- 自然语言查询：「班级有多少人」「积分排名」
- 自然语言操作：「给张三加10分」「记录李四违纪」
- 文件上传分析：上传 Excel 后 AI 自动识别并执行操作
- 支持批量更新学号、录入成绩等
- 所有页面均有悬浮 AI 按钮，随时调用
